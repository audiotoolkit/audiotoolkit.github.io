How It Works

How to Loop an Audio Clip

1. Upload your clip. Drag and drop it into the upload area, or click to browse your device.

2. Choose your mode. "Repeat Count" repeats it an exact number of times. "Target Length" calculates the repeats needed to hit a specific duration.

3. Preview and download. Listen to the start of the loop, then download the full looped file as a WAV.

Why It Matters

Clean, Gapless Looping

This tool joins each repeat directly to the next with no added silence or crossfade, so the loop is as tight as your original clip allows. Everything runs through the Web Audio API in your browser, so even looping a clip 50+ times happens in a couple of seconds with no upload wait.

Good To Know

Getting a Seamless Loop

Trim to a clean start and end point first. If your clip doesn't start and end at a similar volume level, you'll hear a subtle click at each loop boundary — use the Audio Trimmer to find a cleaner cut point.

"Target Length" trims the final repeat. If your target duration doesn't divide evenly into the clip length, the last repeat is cut short so the total length matches exactly.

Common Questions

Frequently Asked Questions

Will the loop have a click or gap between repeats? ▾
This tool joins repeats back-to-back with no added silence. If your original clip doesn't start and end at the same volume level, you may hear a subtle click at each loop point — trimming the clip to start and end on silence, or a matching point in a waveform, gives the cleanest loop.
Can I set an exact target length instead of a repeat count?
Yes. Switch to "Target Length" mode and enter how long you want the final file to be — the tool calculates how many repeats are needed and trims the final repeat if necessary to hit that length exactly.
Is my audio file uploaded to a server?
No. The loop is built locally in your browser using the Web Audio API. Your file is never uploaded.
What's this useful for?
Common uses include background ambience for videos or streams, extending a short sound effect, practice loops for musicians, and simple looping alarm or notification tones.
