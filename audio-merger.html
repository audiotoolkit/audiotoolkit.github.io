How It Works

How to Merge Audio Files

1. Upload two or more files. Drag and drop them together, or click to browse and select multiple at once. You can also add more afterward.

2. Set the order. Use the up and down arrows next to each file to arrange them in the order you want them joined.

3. Merge and download. Click the button and a single combined audio file downloads to your device as a WAV file.

Why It Matters

Why Merge Audio Locally in Your Browser?

Combining clips from different sources usually means different sample rates and channel counts — a phone recording might be 48kHz mono while a downloaded track is 44.1kHz stereo. This tool automatically matches every clip to the same sample rate and channel count before joining them, which server-based tools often charge extra for or handle poorly.

And since everything runs through the Web Audio API in your browser, none of your clips are ever uploaded to a server to be combined.

Good To Know

Tips for Clean Merges

Trim first if you need to. If a clip has unwanted silence or noise at the start or end, use the Audio Trimmer on it before merging, since this tool joins clips exactly as uploaded with no gap.

Order matters. Files are joined in the order shown in the list, top to bottom — use the arrows to reorder before merging, not after.

Large files take a bit longer. Resampling and merging happens in your browser, so combining several long, high-quality files may take a few seconds. The button will show progress while it works.

Common Questions

Frequently Asked Questions

Can I merge files with different sample rates or formats? ▾
Yes. This tool automatically matches every clip to the same sample rate and channel count before joining them, so files from different sources (like a phone recording and a downloaded MP3) merge cleanly without pitch or speed issues.
How many files can I merge?
There's no fixed limit, but merging many long files uses more of your device's memory since everything is processed in the browser rather than on a server.
Can I reorder the clips before merging?
Yes. Use the up and down arrows next to each file in the list to change the order they'll be joined in.
Is there a gap or silence between merged clips?
No, by default clips are joined back-to-back with no added silence. If the original recordings had trailing silence, that will still be present.
Are my files uploaded anywhere?
No. All decoding, resampling, and merging happens locally in your browser using the Web Audio API. Nothing is uploaded.
