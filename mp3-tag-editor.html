How It Works

How to Edit MP3 Tags

1. Upload your MP3. Drag and drop it into the upload area, or click to browse your device.

2. Check the pre-filled fields. If the file already has tags, they're read and filled in automatically — edit whatever needs fixing.

3. Save and download. A new MP3 file downloads with your updated tags, and the same audio data untouched.

Why It Matters

What This Tool Actually Changes

This tool only replaces the ID3 metadata block at the start of the file — the small chunk of data that stores title, artist, album, and similar text fields. The actual audio content is copied through byte-for-byte, unchanged and un-re-encoded, so there's no quality loss whatsoever from editing tags.

Everything happens directly on the file's bytes in your browser, so a private or unreleased track's tags can be fixed without ever uploading the file anywhere.

Good To Know

A Few Notes

This tool covers the common fields — title, artist, album, year, genre, and comment. It doesn't currently support embedding cover art.

Works on MP3 specifically. Other formats (WAV, M4A, FLAC) use different metadata systems that this tool doesn't read or write.

Existing tags aren't lost if you leave a field blank — leaving a field empty and saving will simply omit that tag from the new file, so only fill in what you want to set.

Common Questions

Frequently Asked Questions

What are ID3 tags? ▾
ID3 tags are metadata embedded directly in an MP3 file — title, artist, album, year, genre, and more — which is how music players and phones display song information instead of just a filename.
Will editing tags affect the audio quality?
No. This tool only replaces the metadata block at the start of the file; the actual audio data is copied through unchanged and is not re-encoded.
Does this work on other formats like WAV or M4A?
This tool is built specifically for MP3 files and the ID3v2 tag format. Other formats use different metadata systems and aren't currently supported.
Is my file uploaded to a server?
No. Reading and writing tags happens locally in your browser by directly editing the file's bytes. Your file is never uploaded.
