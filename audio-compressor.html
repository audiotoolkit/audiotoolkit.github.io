Why It Matters

Bitrate Is the Size/Quality Trade-off

An audio file's size is mostly determined by its bitrate — how much data represents each second of sound. Lowering the bitrate shrinks the file by discarding more detail during MP3 encoding, so the two are always a trade-off: smaller files mean somewhat less audio detail. This tool shows you the estimated size at your chosen bitrate before you commit, so you can find the point that balances size and quality for your needs.

Good To Know

Picking a Bitrate

96–128 kbps is a good starting point for voice recordings, podcasts, and lectures — content stays clear at a small file size.

192 kbps is a solid middle ground for music where you want a real size reduction without an obvious quality drop.

320 kbps keeps close to full quality while still being noticeably smaller than an uncompressed WAV — a good choice when you just want a reasonably-sized file with minimal compromise.

A note on the MP3 encoder: compression relies on an encoder library loaded from a public CDN. If it fails to load, this tool falls back to WAV export, which won't reduce file size, rather than producing a broken file.

Common Questions

Frequently Asked Questions

How does reducing file size affect audio quality? ▾
Lower bitrates produce smaller files by discarding more audio detail. 128 kbps is usually fine for voice and casual listening; 192–320 kbps keeps more detail for music. Going below 96 kbps starts to sound noticeably worse for most content.
Can I target an exact file size?
This tool shows a live estimated output size as you adjust the bitrate slider, so you can dial in a bitrate that lands close to a size you need — for example, fitting under an email attachment or upload limit.
Why is the output an MP3 and not the original format?
MP3 at a lower bitrate is how meaningful file size reduction works for audio — re-saving as WAV or another lossless format wouldn't shrink the file. If MP3 encoding is unavailable, this tool falls back to WAV without any size reduction rather than failing outright.
Is my audio file uploaded to a server?
No. Compression happens locally in your browser. Your file is never uploaded.
