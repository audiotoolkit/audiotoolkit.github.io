How It Works

How to Use Voice to Text

1. Tap the microphone button and allow microphone access when your browser asks.

2. Start speaking. Text appears as you talk — lighter gray text is still being processed, and turns solid black once finalized.

3. Tap the microphone again to stop, then copy the text or download it as a .txt file.

Being Upfront

Why This Tool Isn't Fully Private

Every other tool on Audio Toolkit processes your file entirely on your device using the Web Audio API — nothing is ever uploaded. This tool is different: browser speech recognition doesn't run locally. In Chrome, for example, your microphone audio is sent to Google's servers, converted to text there, and sent back. We'd rather tell you this plainly than let you assume it works the same way as everything else here.

If privacy matters for what you're dictating, this isn't the right tool for it.

Good To Know

Getting Better Results

This only works with live speech — it cannot transcribe an audio file you've already recorded. If you have an MP3 or voice memo to transcribe, this tool can't help with that; it's built for dictating out loud in the moment.

Speak clearly and at a normal pace. Very fast speech, heavy background noise, or a poor microphone will reduce accuracy.

Punctuation isn't automatic. Say "comma," "period," or "new line" out loud if you want them inserted, or add punctuation manually afterward.

Common Questions

Frequently Asked Questions

Can this transcribe an audio file I already have, like an MP3? ▾
No, and this is an important limitation to be upfront about. Browser speech recognition only works with live microphone input, not existing audio files. This tool is for dictating out loud in real time, not transcribing a recording you already have.
Is this tool private like the rest of Audio Toolkit?
No, and we want to be upfront about that. Unlike every other tool on this site, which processes audio entirely on your device, browser speech recognition (in Chrome, for example) sends your voice to a cloud service to generate the text. Don't use this for anything sensitive.
Which browsers support this?
Chrome and Edge have the most reliable support. Safari has partial support. Firefox does not support the Web Speech API's recognition feature at all as of this writing.
Why does the transcript sometimes get words wrong?
Speech recognition accuracy depends on your microphone quality, background noise, accent, and speaking pace. Speaking clearly and pausing briefly between sentences generally improves accuracy.
